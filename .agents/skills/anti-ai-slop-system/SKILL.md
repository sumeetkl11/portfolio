# Complete Anti-AI Slop System 🎨⚡

Production-ready architecture rules for building Awwwards-winning personal portfolios and web applications.

## Core Directives
1. **0% AI-Slop**: Reject generic centered pill cards, purple-cyan saturated blob gradients, and stock buzzwords ("Cutting-edge", "Passionate developer", "Seamless").
2. **Pure Pitch Black Void**: For scrollytelling experiences, match background precisely (`#000000`) to canvas/video frames so edges vanish completely into negative space.
3. **Luxury Negative Space**: Give typography and imagery room to breathe. Use asymmetric layouts and bold editorial typography (`Inter`, `SF Pro Display`, `Clash Display`).
4. **Physical Tactility**:
   - Noise/grain overlay for filmic depth.
   - Glassmorphism with 1px translucent borders (`border: 1px solid rgba(255, 255, 255, 0.08)`).
   - Micro-interactions with magnetic hover and tactile spring physics.
5. **Responsive QA**: Verify layout across 375px (mobile), 768px (tablet), and 1440px (desktop). Zero horizontal scroll overflow.
