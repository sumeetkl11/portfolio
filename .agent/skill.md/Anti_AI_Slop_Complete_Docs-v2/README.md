# Complete Anti-AI Slop System 🎨⚡

Yeh directory ek production-ready, award-winning, Apple/Stripe-level website architecture provide karti hai. Antigravity/Cursor jaise AI code editors ke liye ye complete context rules hain taake 0% AI-slop generate ho.

- `01_anti_ai_slop_fundamentals.md`: Core design principles, dynamic bento grids, luxury whitespace, typography.
- `02_framer_motion_animations.md`: Physics-based spring animations, staggered load states, magnetic hover.
- `03_premium_ui_libraries.md`: Aceternity UI, Magic UI setup and visual integration.
- `04_shadcn_customization.md`: Customizing base shadcn elements to eradicate default templates.
- `05_vp0_mcp_integration.md`: Free 21st.dev alternative for direct structured UI sourcing.
- `06_audio_and_haptics_microinteractions.md`: Subtle tactical UI sound effects with `use-sound`.
- `07_noise_glassmorphism_shaders.md`: SVG grain overlay, frosted glass borders, light particle canvas.
- `08_responsive_visual_qa_mcp.md`: Playwright/Puppeteer self-testing guidelines (375px, 768px, 1440px).
- `09_copywriting_and_anti_cliche_rules.md`: Banned buzzword list, authentic punchy headline formulas.
